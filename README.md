# Finalmcuptoject
機車警示系統
# 🏍️ 機車無線連動盲區偵測 安全帽外掛燈系統(實車路測三節點最終版)
功能介紹網站(建議點入觀看):https://sites.google.com/view/finalmcuptojectmotorcyclewire/full-page-embed

本專案為針對機車騎乘安全設計的**無線連動警示系統**，透過 **ESP-NOW 低延遲無線通訊**整合「車頭控制與盲區顯示」、「車尾雙雷射盲區偵測」與「安全帽高視認度外掛燈具」。

系統採用**全無線三節點分散式架構**，徹底免除跨車身實體拉線與引擎點火雜訊對長距離 I2C 訊號的干擾；同時導入**非接觸式磁簧煞車感應**、**方向燈優先控制邏輯**與**雙向心跳斷線保護機制**，確保實車路測的穩定性與騎乘安全。

## 一、 系統架構總覽（三節點無線架構）

```text
┌─────────────────────────────────────────────────────────────────────────┐
│                    [節點 1：車頭控制與顯示端]                             │
│                   ESP32-C3 SuperMini #1 (主控中心)                       │
│  • 輸入：煞車磁簧開關 (GPIO 0)、三段式方向燈撥桿 (GPIO 1 / GPIO 3)        │
│  • 輸出：車頭左右盲區警示 LED (GPIO 6 / GPIO 7)、預留蜂鳴器 (GPIO 10)    │
└───────────────┬─────────────────────────────────────────▲───────────────┘
                │ ESP-NOW (Ch.1 / 每 50ms)                │ ESP-NOW (Ch.1 / 每 50~100ms)
                │ 傳送控制字元: 'L' / 'R' / 'B' / 'N'      │ 回傳盲區狀態: '0' / '1' / '2' / '3'
                ▼                                         │
┌───────────────────────────────┐         ┌───────────────┴───────────────┐
│   [節點 3：安全帽接收顯示端]    │         │    [節點 2：車尾盲區偵測端]     │
│  ESP32-C3 #3 + NUCLEO-G474RE  │         │     ESP32-C3 SuperMini #2     │
│  • UART 橋接轉發控制指令        │         │  • 雙 VL53L1X ToF 雷射測距     │
│  • 100% 沿用階段一狀態機韌體    │         │  • XSHUT 動態分配 I2C 位址     │
│  • N-MOSFET PWM 驅動 3 片燈片  │         │  • I2C 線長壓在 15cm 內抗干擾  │
└───────────────────────────────┘         └───────────────────────────────┘
